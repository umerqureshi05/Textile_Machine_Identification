# 🧵 Textile Machine Identification App

A Streamlit-based educational web application for Textile Engineering
students to learn and identify textile machines, model numbers, process
stages, functions, and working processes.

## 🚀 Features

- Textile machine database
- Machine name and model identification
- Process-stage filtering
- Machine search
- Manufacturer information
- Machine function
- Machine working process
- CIE L*a*b* values
- Machine image upload
- Textile manufacturing process flow
- Interactive dashboard
- Simple and student-friendly interface

## 🏭 Textile Process Stages

The application covers the following textile manufacturing stages:

1. Blow Room
2. Carding
3. Drawing
4. Roving
5. Spinning
6. Winding
7. Warping
8. Sizing
9. Weaving

🌐 Deploy on Streamlit Community Cloud
Create a GitHub repository.
Upload App.py.
Upload requirements.txt.
Upload README.md.
Open Streamlit Community Cloud.
Connect your GitHub repository.
Select App.py as the main file.
Deploy the application.
🎨 Application Design
The application uses a modern engineering-style color scheme:
Navy Blue — Main headings
Green — Machine information
Orange — Process stages
Light Gray — Application background
White — Information cards
Light Blue — LAB value section
🎨 CIE Lab* Values
The application displays three LAB parameters:
L* = Lightness
a* = Green to Red axis
b* = Blue to Yellow axis
The LAB values in the sample database can be replaced with measured values from actual machine surfaces or textile materials.
